# PreChess

PreChess is a mobile-first live prediction market for chess.

Spectators watch the same live game and trade virtual-point outcome shares on short, automatically resolved chess events: checks, captures, castling, queen trades and other deterministic props.

The core product definition is:

- `docs/product/prediction-market.md`

Current repository state is intentionally reset around the new concept. Old winner-only web prototype code and schema have been removed.
